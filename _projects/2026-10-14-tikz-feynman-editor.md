TikZ Feynman Editor provides a visual interface for drawing Feynman diagrams and exporting them as SVG images or LaTeX code for use in papers, notes, and presentations. Inspired by the original TikZ Feynman Editor and quiver, it offers an interactive alternative to writing diagram code by hand. The [online editor](https://haixuan-lin.github.io/tikz-feynman-editor/) runs directly in the browser, and the project can also be built as a macOS application for Apple Silicon.
